# 🚀 Quick Start Guide

Welcome to FocusWall! Get your first custom wallpaper in 5 minutes.

## 📦 Installation

```bash
# Navigate to the project
cd focuswall

# Install dependencies
pnpm install
# or
npm install

# Start the development server
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎯 Create Your First Wallpaper

### Step 1: Add Tasks (30 seconds)
1. Look for the **Task Manager** section (green header)
2. Type your first task in the input field
3. Optionally set a time and select a category
4. Press Enter or click **Add**
5. Add a few more tasks to see them organized by category

### Step 2: Customize Background (1 minute)
1. Find the **Customization** panel (purple header)
2. Click the **Settings** tab
3. Choose your background:
   - **Gradient**: Beautiful built-in gradients (recommended for first try)
   - **Image URL**: Paste any image URL
   - **Upload**: Upload from your computer
4. Select Light or Dark theme
5. Adjust transparency slider if needed

### Step 3: Add Quick Notes (30 seconds)
1. Scroll to **Quick Notes** section (blue header)
2. Type anything you want visible on your wallpaper
3. Click **Save Notes**

### Step 4: Optional - Add Countdown Event (1 minute)
1. Go to **Events** tab in the Customization panel
2. Enter event name (e.g., "Project Deadline")
3. Select date
4. Click **Add Event**

### Step 5: Download Your Wallpaper (30 seconds)
1. Scroll to **Wallpaper Preview** section (orange header)
2. Check the preview - you should see all your tasks!
3. Click the big **Download Wallpaper (1920x1080)** button
4. Wait a moment while it generates
5. Your wallpaper is downloaded! 🎉

## 💡 Pro Tips

### Make Tasks Stand Out
- Use all three categories (Personal, Work, Others)
- Add times to important tasks
- Keep task names concise (30 chars max for best display)

### Background Selection
- For text readability, use images with empty space
- Try Unsplash for free high-quality images: `https://source.unsplash.com/1920x1080/?nature`
- Gradient backgrounds work great with both light and dark themes

### Widget Control
- Click the **Widgets** tab to show/hide specific widgets
- Hide Calendar if you prefer more space for tasks
- Hide Quote if you want a minimalist look

### Theme & Transparency
- Dark theme works better with bright backgrounds
- Increase transparency (50-70%) for subtle widgets
- Decrease transparency (0-30%) for prominent widgets

## 🎨 Customization Ideas

### Minimalist Setup
- Show only Tasks and Quote
- Use gradient background
- Set transparency to 10%

### Information-Rich Setup
- Show all widgets
- Use dark theme
- Add multiple countdown events
- Fill notes with important info

### Work-Focused Setup
- Show Tasks and Calendar
- Add work-related countdown events
- Use professional color scheme (dark theme)

## 🔄 Daily Workflow

1. **Morning:** Update your task list for the day
2. **Anytime:** Check off completed tasks
3. **End of Day:** Download fresh wallpaper for tomorrow
4. **Weekly:** Update countdown events and notes

## 🌓 Theme Switching

- Click the **Moon/Sun icon** in the top-right header
- Changes both the app and wallpaper preview
- Download wallpapers in both themes for different times of day!

## 📊 Track Progress

- Click **Profile** button in the header
- See your task completion rate
- View 7-day activity chart
- Adjust preferences (date format, time format, language)

## 💾 Your Data

All your data is saved automatically in your browser:
- Tasks persist between sessions
- Settings are remembered
- No account needed!

**Note:** Clearing browser data will reset everything.

## ❓ Common Questions

**Q: Can I use this without internet?**  
A: After the first load, yes! It's a local-first app.

**Q: Where is my data stored?**  
A: Only in your browser's localStorage. Nothing is sent to any server.

**Q: Can I download multiple wallpapers?**  
A: Yes! Download as many as you want, anytime.

**Q: What resolution is the wallpaper?**  
A: 1920x1080 (Full HD) - perfect for most monitors.

**Q: Can I use custom fonts?**  
A: The wallpaper uses web-safe fonts that work on all systems.
